UGzeg personal apps

This page belongs to a set of small, single-user tools that are used only by their owner (GitHub user UGzeg). They are not offered to the public and no one else can sign in to them.

Apps

  • health-backup — stores the owner's encrypted server backups in the owner's own Google Drive. It uses only the drive.file scope, so it can see only the files it creates itself.
  • health — reads the owner's own wearable data (for example from Google Health) into the owner's self-hosted server for personal analysis.

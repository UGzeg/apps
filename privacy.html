Privacy policy

Last updated: 2026-11-17

The apps listed on the home page are personal tools used exclusively by their owner. They are not distributed to, or used by, anyone else.

What data is accessed

  • Only data in the owner's own Google account, and only after the owner has explicitly granted access on Google's consent screen.
  • health-backup uses the https://www.googleapis.com/auth/drive.file scope: it can create, read and delete only the files it created itself (encrypted backup archives). It cannot see any other file in the owner's Drive.
  • health reads the owner's own health and fitness data, read-only, to store it on the owner's self-hosted server.

How data is used and stored

  • Data is stored only on the owner's own server and in the owner's own Google Drive.
  • Backups are encrypted before they leave the owner's server.
  • No data is sold, shared with or transferred to third parties.
  • No data is used for advertising.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
